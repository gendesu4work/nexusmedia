## Clutch

Clutch ranks agencies mostly by **verified client reviews**, so the listing matters less than the reviews.

- **Services and focus:** use the percentages above. Clutch's categories are *Web Design*, *Web Development*,
  *Video Production*, *Social Media Marketing* and *Business Process Automation*.
- **Description:** paste the long description.
- **Portfolio:** reuse the 4 items in [../goodfirms/portfolio.md](../goodfirms/portfolio.md) with the same screenshots.
- **Reviews:** after the profile is live, Clutch gives you a review link. Send it to 2–3 past clients. Clutch either
  calls them or has them fill in a form, about 15 minutes. Even one review moves you above the many profiles with none.
