Clipping Studio

Paste a YouTube link, pick a start and end or let Gemini find the funniest moments, then hand the clip to ClipForge. It cuts the dead air, follows the speaker and burns in word-by-word captions.

Latest see GitHubReleased on GitHubWindows 10 and 11
ZIPClippingStudio-win64.zip

The full app, ready to run

Both tabs in one package: the clip downloader and ClipForge. Unzip it anywhere, then open the Creator Studio shortcut; the app starts its own local server and opens in its own window, with no console.

  • Python 3.10 or newer, then run pip install -r requirements.txt once
  • ffmpeg on your PATH for cutting and loudness
  • A Gemini or Claude key is optional; the built-in rules work without one

Low Poly Animation

A fully automated low-poly animator. It comes up with "What if…?" ideas and scores them, Claude animates the one you pick in 3D on your PC, and it renders a 1080×1920 MP4 with music and sound. You review it, ask for changes, then post it now or at a time you pick to four platforms. It even replies to new comments.

Latest main branchUpdated on GitHubWindows, runs locally
ZIPlowpolyanimation-main.zip

The app, with all its code

Unzip it, run npm install once, then double-click Shorts Studio.cmd. It opens in your browser at localhost:8800 with five tabs: Create, Dashboard, Trainer, Comments and Models. Add your own .glb or .gltf model packs in Models; free packs from Kenney or Quaternius work well.

  • Node.js 20 or newer, Google Chrome and ffmpeg on your PATH
  • The Claude Code command line, signed in to a Claude account
  • Buffer, or each platform's own login, for posting

Jarvis

A voice assistant that lives on your PC. Say "Jarvis", ask anything and it answers out loud. It opens your apps, browses in its own Chrome, looks at your screen when you ask, controls Spotify, keeps notes, and asks before it does anything risky.

Latest see GitHubReleased on GitHubWindows 10 (2004+) and 11
EXEJarvis-Setup.exe

Windows installer

A small setup file that does the heavy lifting for you. Leave "Set up Jarvis" ticked on the last screen and a setup window installs the voice, the wake word and the assistant's brain, then restarts Windows once and carries on by itself.

  • Set aside 15 to 30 minutes, mostly downloads
  • A free Google Gemini API key; the setup walks you through making one
  • A microphone and speakers

Install help for Windows. Three steps, about two minutes.

  1. Download the file

    The buttons above fetch the newest release straight from GitHub, so you always get the current build. Nothing to sign up for.

  2. Allow it in SmartScreen

    Windows may warn about an app it hasn't seen often. Choose More info, then Run anyway. The installer is the same file you see on GitHub.

  3. Open it from Start

    The installer adds a Start menu entry. For Clipping Studio, unzip first and open the Creator Studio shortcut; right-click it to pin it to the taskbar.

Where do updates come from?

Each new GitHub release shows up here on its own: the version, size and date on the cards are read live from GitHub.

Do my keys leave my PC?

No. Clipping Studio keeps your Gemini key, Claude key and YouTube cookies in local files on your machine.
